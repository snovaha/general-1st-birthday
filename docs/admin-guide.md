## 🛠️ 문제 해결

### 이미지가 표시되지 않을 때
1. 파일 경로 확인: `src/public/assets/images/`
2. 파일명 정확성 확인
3. 브라우저 캐시 삭제

### 배포가 실패할 때
1. AWS 자격 증명 확인
2. S3 버킷 권한 확인
3. 네트워크 연결 확인

### 설정이 저장되지 않을 때
1. 브라우저 localStorage 확인
2. 개발자 도구 콘솔 에러 확인
3. 파일 권한 확인
