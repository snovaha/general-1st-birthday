# 🚀 호스팅케이알 DNS로 snovaha.com 연결하기 (초간단 버전)

## 📋 개요
- ❌ 도메인 이전 불필요
- ✅ 호스팅케이알에서 DNS 레코드 몇 개만 추가
- ⏱️ 소요시간: 30분 (대부분 대기시간)

## 🔧 1단계: AWS에서 SSL 인증서 요청

터미널에서 실행:
```bash
./setup-cloudfront-with-existing-dns.sh
```

## 🌐 2단계: 호스팅케이알 DNS 설정

### 2-1. 호스팅케이알 관리자 페이지 접속
1. 호스팅케이알 로그인: https://hosting.co.kr
2. **나의 서비스 관리** → **도메인 관리**
3. **snovaha.com** 클릭
4. **DNS 관리** 또는 **네임서버 관리** 클릭

### 2-2. DNS 레코드 추가 (총 3개)

스크립트 실행 후 나오는 정보를 보고 다음 레코드들을 추가:

#### ① SSL 인증서 검증용 레코드 (1-2개)
```
레코드 타입: CNAME
호스트명: _acme-challenge (또는 스크립트에서 알려주는 값)
값: abc123.acm-validations.aws. (스크립트에서 알려주는 값)
TTL: 300
```

#### ② 루트 도메인 연결
```
레코드 타입: CNAME
호스트명: @
값: d104xm32ar1ns2.cloudfront.net
TTL: 300
```

#### ③ www 서브도메인 연결
```
레코드 타입: CNAME
호스트명: www
값: d104xm32ar1ns2.cloudfront.net
TTL: 300
```

## ⏳ 3단계: 완료 대기

- SSL 인증서 검증: 5-30분
- CloudFront 업데이트: 15-30분
- DNS 전파: 1-24시간 (보통 1-2시간)

## 🎉 4단계: 접속 테스트

완료 후 접속 가능한 URL:
- https://snovaha.com
- https://www.snovaha.com

## 🆘 문제 해결

### DNS 레코드 추가가 어려운 경우
호스팅케이알 고객센터: **1588-2030**
- "CloudFront 연결용 CNAME 레코드 추가 도움 요청"
- 이 가이드 화면 캡처해서 보여주기

### 자주 묻는 질문

**Q: 기존 웹사이트가 있는데 문제없나요?**
A: CNAME 레코드는 기존 A 레코드를 덮어쓰므로, 기존 웹사이트는 접속 불가능해집니다.

**Q: 원래대로 되돌리려면?**
A: 추가한 CNAME 레코드들을 삭제하고 기존 A 레코드를 다시 추가하면 됩니다.

**Q: 비용이 발생하나요?**
A: AWS Certificate Manager는 무료, CloudFront 사용량에 따라 소액 과금 (월 1-5달러 예상)

## 📱 최종 확인사항

설정 완료 후:
1. https://snovaha.com 접속 → 한우주 돌잔치 초대장 표시
2. 모바일에서 접속 테스트
3. 네이버 지도 링크 동작 확인
4. 플로팅 메뉴 정상 동작 확인
